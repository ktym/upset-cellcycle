# The phosphatase Cdc14 triggers mitotic exit by reversal of Cdk-dependent phosphorylation

- **PMID**: 9885559
- **Authors**: Visintin R, Craig K, Hwang ES, Prinz S, Tyers M, Amon A
- **Journal**: Mol Cell (1998) 2:709-718
- **DOI**: 10.1016/s1097-2765(00)80286-5
- **URL**: https://pubmed.ncbi.nlm.nih.gov/9885559/
- **関連Interaction ID**: `SCE-CC-049` (`CDC14` → `CDH1`), `SCE-CC-050` (`CDC14` → `SIC1|SWI5`)

## 細胞周期制御に関する概要要約

真核細胞が分裂期を脱出（mitotic exit）するためには、M期サイクリン依存性キナーゼ（CDK）の不活性化が必須である。本研究では、出芽酵母のタンパク質ホスファターゼCdc14が、CDK依存的なリン酸化を逆転（脱リン酸化）させることでCDK不活性化と分裂期脱出を引き起こすマスター制御因子であることを明らかにした。具体的には、Cdc14はAPC/C活性化因子Cdh1（Hct1）を脱リン酸化・活性化してClbサイクリンのAPC依存的分解を誘導するとともに、転写因子Swi5を脱リン酸化してSIC1の転写を活性化し、かつCDK阻害因子Sic1自体も脱リン酸化して安定化させるという3つの協調的経路を介してClb-Cdc28活性を消去することが示された。
