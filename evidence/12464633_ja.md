# Conserved homeodomain proteins interact with MADS box protein Mcm1 to restrict ECB-dependent transcription to the M/G1 phase of the cell cycle

- **PMID**: 12464633
- **Authors**: Pramila T, Miles S, GuhaThakurta D, Jemiolo D, Breeden LL
- **Journal**: Genes Dev (2002) 16:3034-3045
- **DOI**: 10.1101/gad.1034302
- **URL**: https://pubmed.ncbi.nlm.nih.gov/12464633/
- **関連Interaction ID**: `SCE-CC-061` (`YOX1|YHP1` → `MCM1`)

## 細胞周期制御に関する概要要約

出芽酵母のM/G1期境界においては、Early Cell Cycle Box（ECB）エレメントを介してCLN3、SWI4、CDC6、およびMCMファミリー遺伝子など、G1/S期進行およびDNA複製開始に必須な遺伝子群の一過的な転写が誘導される。ECBにはMADSボックスタンパク質Mcm1が恒常的に結合しているが、その転写活性がどのようにしてM/G1期のみに限定されるかは不明であった。本研究では、2つのホメオドメインタンパク質Yox1およびYhp1がMcm1と直接結合し、ECBエレメント上で転写抑制複合体を形成することを明らかにした。Yox1およびYhp1はG1/S期からM期にかけて発現してECB上のMcm1に結合し転写を抑制することで、ECB依存的転写をM/G1期に厳密に限定する役割を担っている。
