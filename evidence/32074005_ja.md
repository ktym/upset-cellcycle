# Spindle pole bodies function as signal amplifiers in the Mitotic Exit Network

- **PMID**: 32074005
- **Authors**: Ian W. Campbell, Xiaoxue Zhou, Angelika Amon
- **Journal**: Molecular Biology of the Cell (2020) 31:906-916
- **DOI**: 10.1091/mbc.E19-10-0584
- **URL**: https://pubmed.ncbi.nlm.nih.gov/32074005/
- **関連Interaction ID**: `SCE-CC-N38` (`LTE1` → `KIN4`), `SCE-CC-N40` (`CDC15` → `NUD1`), `SCE-CC-N41` (`NUD1` → `DBF2|MOB1`)

## 細胞周期制御に関する概要要約

出芽酵母の分裂期脱出ネットワーク（MEN）は、核の位置情報を分裂期脱出シグナルへと変換するRas様シグナル伝達カスケードである。本研究（PMC7185974）は、MEN構成因子が中心体相当構造である紡錘体極体（SPB）上にスキャフォールドされることで、どのように紡錘体位置と分裂期終盤の進行が共役されるかを定量的に解析した。芽（娘細胞）におけるLte1によるKin4の娘側SPB（dSPB）からの排除、およびSPBスキャフォールドNud1のCdc15によるリン酸化とそれに続くDbf2–Mob1のリクルート・活性化という一連のステップを通じて、SPBが単なるオン/オフスイッチではなくシグナル増幅器（signal amplifier）として機能することが示された。

  > "The Mitotic Exit Network (MEN), a budding yeast Ras-like signal transduction cascade, translates nuclear position into a signal to exit from mitosis.
