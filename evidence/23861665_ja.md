# Budding Yeast Greatwall and Endosulfines Control Activity and Spatial Regulation of PP2A(Cdc55) for Timely Mitotic Progression

- **PMID**: 23861665
- **Authors**: Maria Angeles Juanes, Rita Khoueiry, Thomas Kupka, Anna Castro, Ingrid Mudrak, Egon Ogris, Thierry Lorca, Simonetta Piatti
- **Journal**: PLoS Genetics (2013) 9:e1003575
- **DOI**: 10.1371/journal.pgen.1003575
- **URL**: https://pubmed.ncbi.nlm.nih.gov/23861665/
- **関連Interaction ID**: `SCE-CC-N26` (`RIM15` → `IGO1|IGO2`), `SCE-CC-N27` (`IGO1|IGO2` → `CDC55`)

## 細胞周期制御に関する概要要約

真核生物においてGreatwallキナーゼはエンドスルフィン（endosulfine）ファミリータンパク質をリン酸化し、リン酸化されたエンドスルフィンがPP2A-B55ホスファターゼに結合・阻害することで分裂期進入を制御する。本研究は、出芽酵母のGreatwallオルソログであるRim15キナーゼがエンドスルフィンIgo1およびIgo2をリン酸化し、これによってIgo1/2が細胞周期依存的にPP2A-Cdc55に結合することを示した。リン酸化されたIgo1はin vitroでPP2A-Cdc55活性を阻害するとともに、酵母細胞内ではPP2A-Cdc55の核外移行と機能調節にも関与し、Cdk1活性化の正のフィードバックループを介して適時の分裂期進入を促進する。
