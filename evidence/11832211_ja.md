# Separase, polo kinase, the kinetochore protein Slk19, and Spo12 function in a network that controls Cdc14 localization during early anaphase

- **PMID**: 11832211
- **Authors**: Stegmeier F, Visintin R, Amon A
- **Journal**: Cell (2002) 108:207-220
- **DOI**: 10.1016/s0092-8674(01)00634-1
- **URL**: https://pubmed.ncbi.nlm.nih.gov/11832211/
- **関連Interaction ID**: `SCE-CC-057` (`ESP1|SLK19|SPO12|CDC5` → `CDC14`)

## 細胞周期制御に関する概要要約

出芽酵母のタンパク質ホスファターゼCdc14は分裂期脱出に必須であり、G1期からM期中期にかけては核小体内の阻害因子Net1（Cfi1）に結合して隔離されている。これまでCdc14の核小体からの放出は後期終期に働くMitotic Exit Network（MEN）のみによって制御されると考えられていた。本研究では、後期（アナフェーズ）初期にCdc14の核小体からの一過的な放出を促進する新たな制御経路を発見し、FEAR（Cdc Fourteen Early Anaphase Release）ネットワークと命名した。FEARネットワークはセパラーゼ（Esp1）、ポロ様キナーゼ（Cdc5）、動原体タンパク質Slk19、およびSpo12から構成され、後期初期に放出されたCdc14がMENを活性化することで効率的な分裂期脱出を保証することが示された。
