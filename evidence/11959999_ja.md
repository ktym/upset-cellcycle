# Bfa1 can regulate Tem1 function independently of Bub2 in the mitotic exit network of Saccharomyces cerevisiae

- **PMID**: 11959999
- **Authors**: Ro HS, Song S, Lee KS
- **Journal**: Proc Natl Acad Sci U S A (2002) 99:5436-5441
- **DOI**: 10.1073/pnas.062059999
- **URL**: https://pubmed.ncbi.nlm.nih.gov/11959999/
- **関連Interaction ID**: `SCE-CC-055` (`BUB2|BFA1` → `TEM1`)

## 細胞周期制御に関する概要要約

出芽酵母の分裂期脱出ネットワーク（MEN）において、Ras様GTPアーゼTem1は上流の活性化スイッチとして働き、紡錘体極体（SPB）に共局在するBub2およびBfa1によって負に制御される。Bub2とBfa1は複合体を形成してTem1に対する2成分GAP（GTPアーゼ活性化タンパク質）として機能するが、本研究ではBfa1がBub2非依存的にもTem1を阻害できることを明らかにした。BFA1の過剰発現はbub2欠損株においても強力なM期終期（テロフェーズ）停止を誘導し、Bfa1がTem1に直接結合して下流エフェクターであるCdc15とTem1との相互作用を阻害することが示された。したがって、Bub2–Bfa1は2成分GAPとしてTem1を不活性化するだけでなく、Bfa1単独でもTem1とCdc15の会合を阻害することで二重にTem1機能を抑制している。
