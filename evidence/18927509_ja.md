# The Polo-like kinase Cdc5 interacts with FEAR network components and Cdc14

- **PMID**: 18927509
- **Authors**: Rahal R, Amon A
- **Journal**: Cell Cycle (2008) 7:3262-3272
- **DOI**: 10.4161/cc.7.20.6852
- **URL**: https://pubmed.ncbi.nlm.nih.gov/18927509/
- **関連Interaction ID**: `SCE-CC-060` (`CDC5` → `CDC14|ESP1|SLK19`)

## 細胞周期制御に関する概要要約

出芽酵母においてホスファターゼCdc14は分裂期脱出に必須であり、後期（アナフェーズ）初期にはFEAR（Cdc Fourteen Early Anaphase Release）ネットワークによって、後期終期にはMitotic Exit Network（MEN）によって核小体からの放出が制御される。ポロ様キナーゼCdc5はFEARネットワークとMENの両方の構成因子としてCdc14放出に中心的な役割を果たすが、FEARネットワーク内での分子機構は十分に解明されていなかった。本研究では、Cdc5がFEARネットワークの構成因子であるセパラーゼEsp1および動原体結合タンパク質Slk19と物理的に会合し、さらにCdc14とも直接結合することを明らかにした。これらの相互作用にはCdc5の保存されたPolo-boxドメイン（ホスホセリン/ホスホトレオニン結合ドメイン）が必須であり、Polo-boxドメインを介した複合体形成が後期初期におけるCdc14の放出促進に不可欠であることが示された。
